
# 🍔 Santo Burguer

Projeto de um site de hamburgueria desenvolvido em HTML e CSS.

## 📌 Descrição
Site institucional da hamburgueria Santo Burguer, contendo:
- Página inicial
- História da hamburgueria
- Cardápio de lanches e combos
- Formulário para cadastro do cliente

## 🛠 Tecnologias utilizadas
- HTML5
- CSS3

## 📂 Estrutura do projeto
- index.html → Página inicial
- onde_tudo_comecou.html → História da hamburgueria
- cadastro.html → Formulário de cadastro
- Scheila.css → Estilos do site
- imagens/ → Imagens do projeto

## 🚀 Como visualizar o projeto
Abra o arquivo `index.html` em qualquer navegador (Chrome, Edge, Firefox).

## 📱 Responsividade
O site é responsivo e pode ser visualizado em:
- Notebook
- Tablet
- Celular
